## Summary

Download Agent v2 replaces the push-path (container → Supabase) with an egress-proof pull-path. The Supabase Edge Functions gateway hangs on request bodies >= ~1 MB, blocking the old push path. The pull path reverses the direction: Edge Function fetches the bundle from the container via a single-use token, then uploads to Storage.

## Security properties

- Binding secret: `timingSafeEqual` (constant-time, length-checked)
- Bundle token: single-use, 10-min TTL, memory-only Map, 24-byte hex randomUUID
- Passphrase: never written to disk/logs, returned in JSON only
- File cleanup: on ALL paths (success, error, client disconnect, timeout, spawn failure)
- No SSRF: probe targets are fixed constants
- Proxy-owned path: child-reported `outputPath` must match or 500
- Size cap: 100 MB enforced before streaming (6 Deno tests)
- Process-group kill: `detached: true` + `process.kill(-pid)` for tar grandchild
